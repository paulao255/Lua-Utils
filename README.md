# Lua-Utils

A Lua utilities library working with Lua 5.1 and LuaJIT.

## Installation

Install `Luarocks` and `Lua 5.1` or `LuaJIT` and paste this command as an administrator (`sudo` on POSIX) to install Lua-Utils: `luarocks --lua-version=5.1 install --server=https://luarocks.org/manifests/paulao255 lua-utils develop-1`.
